## How to resume next session

### Quick start
```bash
cd /Users/muazhusaini/Documents/Project/fitmu/mobile
npx expo start --web --port 8081
open http://localhost:8081
```

### To get login actually working (next priority)
1. Go to [supabase.com](https://supabase.com) → New Project → name `fitmu`
2. Copy Project URL + anon key to `mobile/.env`:
   ```
   EXPO_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
   EXPO_PUBLIC_SUPABASE_ANON_KEY=eyJhb...
   ```
3. In Supabase SQL Editor, run each migration file in order
4. Supabase Auth → URL config → add `fitmu://localhost` to redirect URLs
5. Restart Expo: `npx expo start --web --clear`

### To deploy AI features
```bash
cd /Users/muazhusaini/Documents/Project/fitmu
supabase login
supabase link --project-ref YOUR_REF
supabase secrets set ANTHROPIC_API_KEY=sk-ant-...
supabase functions deploy ai-coach
supabase functions deploy ai-workout
supabase functions deploy ai-meals
```

### To unlock iOS Simulator (if wanted later)
- Install Xcode from App Store (~15GB download)
- `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`
- `npx expo run:ios`

## Decisions made this session

| Decision | Reason |
|---|---|
| Expo + React Native (not Swift) | User has no mobile background, JS more approachable |
| NativeWind v4 + Tailwind v3 (downgraded from v4) | NativeWind doesn't support Tailwind v4 yet |
| `babel-preset-expo@~54.0.0` (downgraded from 55) | Match Expo SDK 54 |
| `nativewind/babel` is a PRESET, not plugin | Caused `.plugins is not valid Plugin property` error |
| `app/index.tsx` redirect added | Required by Expo Router or `/` is 404 |
| Auth guard simplified — no blocking spinner | 3s timeout never fires under virtual time, made initial render blank |
| Web localStorage fallback for Supabase storage | `expo-secure-store` is iOS/Android-only |
